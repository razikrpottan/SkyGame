# ✈️ SkyGame

**SkyGame** is a Java-based airplane shooting game where players take control of an aircraft, battle enemy planes, and aim for the highest score.

## 🎮 About the Game

SkyGame is a desktop game built with Java. It focuses on airplane combat, enemy encounters, and an engaging gameplay experience.

## ✨ Features

- ✈️ Player-controlled airplane
- 🎯 Enemy airplane combat
- 🔥 Shooting mechanics
- 📈 Increasing game speed as travel distance increases
- 🏆 High-score tracking
- 🎮 Interactive gameplay

*Note: Features listed here reflect the intended game description; adjust them if any are not yet implemented.*

## 🛠️ Built With

- **Java** — Game programming
- **Maven** — Project and dependency management
- **IntelliJ IDEA** — Development environment

## 📋 Requirements

- Java Development Kit (JDK)
- Apache Maven, or IntelliJ IDEA with Maven support
- Git (optional, for cloning the repository)

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/razikrpottan/SkyGame.git
```

### 2. Open the project

Open the `SkyGame` folder in IntelliJ IDEA and allow Maven to import the project.

### 3. Run the game

Locate `MainMenu.java` in `src/main/java/` and run its `main()` method, if it contains one. Otherwise, run the class containing the game's entry point.
